  • Auto drop
  • Auto pickup filter
  • Streamer mode

  • Windows 10 / 11 x64
  • WDK (Windows Driver Kit)
  • Visual Studio 2022
  • Fortnite installed
  • Test mode enabled for driver

Installation

# Build usermode with MSVC cl /EHsc /Fe:embernite.exe embernite_usermode.cpp embernite_scripts.cpp embernite_advanced.cpp embernite_main.cpp
